## 🛠️ 技术栈

### 后端技术栈
- **框架**：Spring Boot 3.x
- **安全**：Spring Security + JWT
- **ORM**：MyBatis-Plus 3.5.x
- **数据库**：MySQL 8.0
- **API文档**：SpringDoc OpenAPI 2.3.0 + Knife4j 4.3.0
- **工具库**：Lombok

### 数据库设计
- **字符集**：utf8mb4
- **存储引擎**：InnoDB
- **删除策略**：逻辑删除（is_deleted字段）
- **外键约束**：无（手动处理级联）
- **索引**：主键索引 + 唯一索引

## 🔧 核心功能详解

### 1. 用户认证模块
**功能**：
- 用户注册（支持三种角色：学生、商家、管理员）
- 用户登录（用户名+密码，返回JWT Token）
- Token验证（JWT过滤器自动验证）
- 权限校验（基于角色的访问控制）
- 密码加密（BCrypt加密）

**特点**：
- Token有效期：30天
- 密码加密：BCrypt
- 权限注解：@PreAuthorize

### 2. 文件上传模块
**功能**：
- 图片上传（上传到本地服务器）
- 图片删除（删除本地文件）

**特点**：
- 文件大小限制：5MB
- 文件命名：yyyyMMdd_UUID.extension
- 存储路径：本地文件系统

### 3. 用户管理模块
**功能**：
- 查询用户信息
- 修改用户信息（昵称、头像、手机号）
- 修改密码（旧密码验证）
- 禁用/启用用户

**特点**：
- 密码修改需验证旧密码
- 管理员可禁用/启用用户
- 用户资料分离存储（User + UserProfile）

### 4. 商家管理模块
**功能**：
- 创建商家（提交审核）
- 修改商家信息
- 查询商家信息
- 商家列表查询（分页、关键词、状态筛选）
- 商家审核（通过/驳回）
- 商家状态管理（启用/禁用）

**特点**：
- 商家需要审核才能使用
- 审核驳回需填写理由
- 已通过的商家不能修改审核状态
- 商家状态影响菜品和活动

### 5. 菜品管理模块
**功能**：
- 创建菜品
- 修改菜品
- 删除菜品（逻辑删除）
- 菜品列表查询（分页、关键词、商家、分类、状态筛选）
- 菜品上下架
- 菜品分类管理（CRUD）

**特点**：
- 菜品上下架控制是否可见
- 支持分类管理
- 菜品包含销量和评分
- 只有上线的菜品可以被推荐

### 6. 评价管理模块
**功能**：
- 发表评价（学生对菜品发表评价）
- 评价列表查询（分页、关键词、商家、菜品、用户、状态筛选）
- 评价审核（管理员审核）
- 删除评价（学生删除自己的评价）
- 评价点赞
- 评价踩
- 取消点赞/踩

**特点**：
- 评价需要审核才能显示
- 支持多张评价图片
- 点赞和踩互斥
- 点赞/踩数据用于排序

### 7. 收藏管理模块
**功能**：
- 收藏店铺/菜品
- 取消收藏
- 收藏列表查询（可筛选类型）
- 检查收藏状态

**特点**：
- 支持收藏商家和菜品
- 只能取消自己的收藏
- 收藏列表包含完整信息
- 支持按类型筛选

### 8. 公告管理模块
**功能**：
- 发布公告（管理员）
- 修改公告
- 删除公告（逻辑删除）
- 公告列表查询（关键词、状态筛选）
- 发布公告（草稿→已发布）

**特点**：
- 支持草稿和已发布状态
- 草稿发布时自动设置发布时间
- 支持关键词搜索
- 只能管理员操作

### 9. 活动管理模块
**功能**：
- 发布活动（商家提交审核）
- 修改活动（仅待审核/已驳回可修改）
- 删除活动（逻辑删除）
- 活动列表查询（分页、关键词、状态、商家筛选）
- 活动审核（管理员审核）
- 添加活动图片
- 删除活动图片

**特点**：
- 活动需要审核
- 已通过审核的活动不能修改
- 支持多张活动图片
- 活动图片支持排序
- 只能删除/修改自己的活动

### 10. 推荐模块
**功能**：
- 热度推荐（根据销量和评分推荐热门菜品）
- 分类推荐（按分类推荐热门菜品）

**特点**：
- 热度计算：销量 × 0.7 + 评分 × 10 × 0.3
- 只推荐上线的菜品
- 支持指定推荐数量（默认10个）
- 分类推荐可指定分类ID

## 💡 开发规范

### 1. 代码规范
- 遵循阿里巴巴Java开发规范
- 使用Lombok简化代码
- 代码需要添加适当注释
- 方法命名规范：驼峰命名
- 类命名规范：大驼峰命名

### 2. 接口规范
- 统一响应格式：Result<T>
- 统一错误码：BusinessException
- 统一异常处理：GlobalExceptionHandler
- 参数校验：@Valid
- 事务管理：@Transactional

### 3. 安全规范
- 密码必须使用BCrypt加密
- Token有效期30天
- 敏感信息不返回前端
- 使用@PreAuthorize注解控制权限
- 所有接口需要认证（部分除外）

### 4. 数据库规范
- 所有删除操作使用逻辑删除
- 字段命名使用下划线分隔
- 所有表都有4个通用字段（creator_id、updater_id、create_time、update_time）
- varchar字段长度根据实际情况设置
- 每个字段都有合理的注释

## 🚀 启动说明

### 1. 数据库配置
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/campus_food?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password
```

### 2. JWT配置
```yaml
jwt:
  secret: your_secret_key_at_least_256_bits
  expiration: 2592000000  # 30天（毫秒）
```

### 3. 文件上传配置
```yaml
file:
  upload-path: E:/upload/campus-food/
  max-size: 5242880  # 5MB（字节）
```

### 4. 启动项目
1. 确保MySQL服务已启动
2. 确保数据库已创建并导入数据
3. 在IDEA中打开项目
4. 运行CampusFoodApplication.java
5. 访问Knife4j文档：http://localhost:8080/doc.html

## 📝 注意事项

### 1. IDE问题处理
如果遇到"找不到符号"错误：
1. **Maven重新导入**：右键项目 → Maven → Reload Project
2. **清理缓存**：File → Invalidate Caches → Invalidate and Restart
3. **重新构建**：Build → Rebuild Project
4. **检查依赖**：确保pom.xml中的依赖已下载

### 2. 常见问题
- **JWT密钥长度不足**：确保jwt.secret至少32个字符
- **文件上传路径问题**：确保路径存在且有写权限
- **数据库连接失败**：检查MySQL服务是否启动，用户名密码是否正确
- **CORS跨域问题**：前端需要配置代理或后端允许跨域

### 3. 测试建议
1. 使用Knife4j在线测试接口
2. 使用Postman测试接口
3. 测试正常流程和异常流程
4. 检查所有CRUD操作
5. 验证权限控制是否生效
