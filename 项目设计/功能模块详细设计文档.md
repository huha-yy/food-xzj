## 二、用户认证模块

### 2.1 模块概述

负责用户注册、登录、认证授权等功能，基于Spring Security + JWT实现。

### 2.2 功能列表

| 序号 | 功能名称 | 说明 | 优先级 |
|------|----------|------|--------|
| 1 | 用户注册 | 用户名+密码注册，支持三种角色 | 高 |
| 2 | 用户登录 | 用户名+密码登录，返回JWT Token | 高 |
| 3 | Token验证 | 验证JWT Token有效性 | 高 |
| 4 | 权限校验 | 基于角色的权限控制 | 高 |
| 5 | 密码加密 | 使用BCrypt加密存储 | 高 |

---

### 2.3 功能详细设计

#### 2.3.1 用户注册

**功能描述**：用户通过用户名+密码注册系统，支持选择角色（学生/商家/管理员）

**输入参数**：
```json
{
  "username": "string",      // 用户名，必填，唯一
  "password": "string",      // 密码，必填，6-20位
  "role": "enum",           // 角色，必填，STUDENT/MERCHANT/ADMIN
  "phone": "string",        // 手机号，选填
  "studentNo": "string"     // 学号，选填（学生必填）
}
```

**输出结果**：
```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "userId": 1,
    "username": "stu001",
    "role": "STUDENT"
  }
}
```

**业务流程**：
```
1. 校验用户名格式（3-32位字母数字下划线）
2. 校验密码格式（6-20位，包含字母和数字）
3. 检查用户名是否已存在
4. 使用BCrypt加密密码
5. 创建用户记录
6. 如果是商家，初始化user_profile记录
7. 返回注册成功信息
```

**异常处理**：
- 用户名已存在 → 返回错误码4001
- 密码格式不正确 → 返回错误码4002
- 参数校验失败 → 返回错误码4000

---

#### 2.3.2 用户登录

**功能描述**：用户通过用户名+密码登录，验证成功后返回JWT Token

**输入参数**：
```json
{
  "username": "string",   // 用户名，必填
  "password": "string"    // 密码，必填
}
```

**输出结果**：
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userId": 1,
    "username": "stu001",
    "role": "STUDENT",
    "nickname": "张三"
  }
}
```

**业务流程**：
```
1. 校验用户名和密码是否为空
2. 根据用户名查询用户信息
3. 检查用户是否存在
4. 检查用户状态是否为ACTIVE
5. 使用BCrypt验证密码
6. 生成JWT Token（有效期30天）
7. 返回Token和用户基本信息
```

**异常处理**：
- 用户不存在 → 返回错误码4011
- 密码错误 → 返回错误码4012
- 用户已禁用 → 返回错误码4013

---

#### 2.3.3 Token验证

**功能描述**：验证JWT Token的有效性，提取用户信息

**实现方式**：通过Spring Security Filter实现，对所有需要认证的接口进行拦截验证

**验证流程**：
```
1. 从请求头获取Authorization字段
2. 提取Bearer Token
3. 验证Token签名
4. 验证Token是否过期
5. 解析Token获取用户信息
6. 将用户信息存入SecurityContext
7. 放行请求
```

**异常处理**：
- Token不存在 → 返回错误码4014
- Token签名错误 → 返回错误码4015
- Token已过期 → 返回错误码4016

---

#### 2.3.4 权限校验

**功能描述**：基于角色的权限控制，不同角色访问不同接口

**权限配置**：

| 角色 | 可访问接口 |
|------|-----------|
| **管理员（ADMIN）** | 所有接口 |
| **商家（MERCHANT）** | 商家管理、菜品管理、活动管理、自己的评价查询 |
| **学生（STUDENT）** | 浏览、评价、收藏、互动、个人中心 |

**实现方式**：
- 使用Spring Security注解 `@PreAuthorize`
- 在Controller方法上添加权限控制

```java
@PreAuthorize("hasRole('ADMIN')")
public Result<Void> deleteUser(Long userId) { }

@PreAuthorize("hasAnyRole('ADMIN', 'MERCHANT')")
public Result<Merchant> getMerchantInfo(Long merchantId) { }

@PreAuthorize("hasRole('STUDENT')")
public Result<Void> publishReview(ReviewDTO reviewDTO) { }
```

---

#### 2.3.5 密码加密

**功能描述**：使用BCrypt算法加密密码

**加密参数**：
- 算法：BCrypt
- 强度：10轮（默认值）

**加密流程**：
```
1. 用户注册/修改密码时，获取明文密码
2. 使用BCryptPasswordEncoder加密
3. 将加密后的哈希值存入数据库
```

**验证流程**：
```
1. 用户登录时，获取输入的密码
2. 从数据库获取存储的密码哈希值
3. 使用BCryptPasswordEncoder验证
4. 返回验证结果
```

#### 6.3.3 更新菜品平均评分

**功能描述**：评价发表或删除后，更新菜品的平均评分

**算法设计**：
```
1. 查询该菜品所有已审核通过的评价（audit_status='APPROVED'）
2. 计算所有评价的评分平均值

4. 更新food表的rating_avg字段
5. 更新updater_id和update_time
```

**计算公式**：
```
rating_avg = SUM(rating) / COUNT(review_id)
```

**触发时机**：
- 评价审核通过后
- 评价删除后

    @ExceptionHandler(MethodArgumentNotValidException.class)
