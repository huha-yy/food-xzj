## 五、开发规范

### 代码规范
1. 遵循 React 编程规范
2. 使用函数组件和 Hooks
3. 使用 Ant Design 组件库
4. 合理使用 useMemo 和 useCallback 优化性能
5. 组件文件使用 .jsx 扩展名
6. 组件内部使用驼峰命名

### 样式规范
1. 使用 CSS Modules 或独立 CSS 文件
2. 遵循 BEM 命名规范
3. 响应式设计，适配不同屏幕尺寸
4. 使用 flexbox 和 grid 布局

### API 调用规范
1. 统一使用 api 目录下的接口函数
2. 使用 async/await 处理异步操作
3. 统一错误处理和提示
4. 合理使用 loading 状态

### 路由规范
1. 使用 React Router 6
2. 路由配置在 router/index.jsx
3. 使用 lazy loading 优化性能
4. 路由守卫（权限控制）
