## 四、颜色使用规范

### 正面状态（积极、成功、主要）
```css
background: linear-gradient(135deg, #4096ff 0%, #1677ff 100%);
color: #4096ff / #1677ff;
```
**应用场景**:
- 主按钮
- 选中状态
- 标签（价格、分类等）
- 统计数据
- 链接文字
- 评分星星

### 负面状态（消极、失败、删除）
```css
background: linear-gradient(135deg, #8c8c8c 0%, #595959 100%);
color: #8c8c8c;
```
**应用场景**:
- 已下架状态
- 驳回状态
- 踩按钮
- 删除操作

### 中性状态（待定、默认、背景）
```css
background: #fafafa / #f5f5f5;
color: #666 / #888;
```
**应用场景**:
- 卡片背景
- 未选中状态
- 辅助文字
- 分割线

### 特殊状态（警告、待审核）
```css
background: linear-gradient(135deg, #fa8c16 0%, #d46b08 100%);
color: #fa8c16;
```
**应用场景**:
- 待审核状态

## 七、注意事项

1. **渐变方向**: 统一使用 `135deg`（从左上到右下）
2. **悬停态**: 主按钮悬停使用 `#69b1ff → #4096ff`
3. **阴影颜色**: 蓝色主题使用 `rgba(22, 119, 255, 0.x)`
4. **文字颜色**: 蓝色主题主要使用 `#4096ff` 和 `#1677ff`
5. **边框颜色**: 使用浅蓝色或浅灰色
